# Tengu AI 8.1 Alpha 2 — Android

В этом репозитории находится **исходный Android-проект Tengu AI**. Старый проект сохранён в ветке [backup-before-tengu-2026-11-11](../../tree/backup-before-tengu-2026-11-11).

## Скачать приложение

- [Actions — сборка APK](../../actions/workflows/android-apk.yml): откройте **Run workflow**. После успешной сборки APK появится в **Artifacts**.
- [Releases — APK](../../releases): при успешной сборке публикуется файл `Tengu_AI_8.1_alpha2.apk`.

**Важно:** APK пока НЕ был собран и проверен на Android. Если Actions завершится ошибкой, установочного файла не будет: нужно исправить ошибки сборки.

## Содержимое

Полный Android-проект со всеми исходниками, ресурсами, тестами и инструкциями находится в [Tengu_AI_8_1_Alpha2_Android_Source.zip](./Tengu_AI_8_1_Alpha2_Android_Source.zip) (≈1,65 МБ). Это настоящий архив исходников, а не заглушка.

Для локальной работы скачайте архив и распакуйте папку `Tengu_Android`. Полная инструкция и протокол тестирования внутри (`README_RU.txt`, `TEST_PLAN.txt`).

## Как работает Tengu

Подготовлена локальная интеграция с GGUF через llama.cpp + Android JNI, но реальная компиляция и запуск модели **не подтверждены**. GGUF-модель в архив не входит, её надо импортировать отдельно после установки. Математический модуль сохранён. Есть работа с фото, карточками WB, музыка и поиск. Tengu-4 зарезервирована до тестов.
