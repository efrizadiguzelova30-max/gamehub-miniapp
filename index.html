СПРАВОЧНЫЙ ЦЕНТР

Как пользоваться LUNIUM

Краткая инструкция по разделам, музыке и безопасности.

Как найти совет по игре?

Открой «Игры», найди игру через поиск и нажми кнопку со стрелкой на её карточке.

Как работает поиск Roblox ID?

Укажи публичное имя пользователя. Если Roblox вернёт несколько совпадений, выбери правильный профиль по отображаемому имени.

Есть ли настоящий ИИ-чат?

Пока нет. Для него нужен сервер, который безопасно хранит ключ ИИ. Нельзя помещать секретный API-ключ в публичные файлы сайта.

Есть ли поиск по личным данным?

Нет. GameHub не предназначен для поиска адресов, телефонов, паролей, скрытых профилей или иной частной информации.

Защищены ли формы от спама?

На странице есть базовая клиентская проверка и ограничение частоты запросов. Это не заменяет серверную защиту; её нужно настроить на backend перед публичным масштабированием.

ЗАКРЫТЫЙ РАЗДЕЛ

Управление GameHub

Раздел управления. Привилегированные действия доступны только после проверки Telegram на защищённом сервере.

Сервер управления недоступен

Админ-сервер пока не подключён. Интерфейс отображается, но управление ботом, сайтом и ролями останется закрытым до настройки Cloudflare Worker и Telegram ID владельца.
